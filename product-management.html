Product Requirements Document (PRD)

Overview: Teachers reported several usability issues and missing features in the current LMS gradebook, particularly around assignment categorization, grade weighting, pacing guide integration, and grading workflows. This project defines a revised gradebook experience that allows teachers to customize grading categories, automate pacing-based scoring, and improve navigation and efficiency.

The revised gradebook will allow teachers to define assignment categories and weights per course section, reflect those weights in automatic grade calculations, improve visibility into student submissions and grading status, and support resubmission indicators and better filtering by section or course.

Problem Statement: The existing gradebook lacks flexibility for teachers to categorize assignments by type, define grade weighting systems per section, filter or search efficiently, or automatically calculate pacing-related zeros. These limitations lead to frustration, inconsistent grading, and reduced accuracy in progress reporting.

Goals & Metrics: Improve grading flexibility (90% success in configuration), reduce grading time by 25%, ensure accuracy of weighted grades, and achieve satisfaction ratings ≥4.5/5.

Stakeholders: Teachers, Academic Admins, Engineering, QA, Product.

User Stories: Teachers can assign weights totaling 100%; label assignments by category; filter by course/section; identify resubmissions via color; and see pacing-based zeros.

High-Level Requirements: Category setup, weight setup, grade calculation fallback, filtering, search, navigation, visual indicators, pacing integration.

Risks & Mitigation: Weight entry errors (validate to 100%), missing pacing data (warning display), setup complexity (guided wizard).

Future Enhancements: Import/export configurations, analytics dashboard, bulk-edit tools.

Functional Specification Document (FSD)

Overview: This specification defines the functional and behavioral requirements for the Gradebook Revision project. The goal is to provide teachers with greater control and efficiency through category weighting, pacing integration, visual indicators, and enhanced navigation.

User Flow: Assignment setup adds category dropdown with default 'Assignment'; gradebook setup prompts teacher to enter weights totaling 100%; grading workflow supports keyboard navigation, autofill, and cell color changes for submissions.

System Behavior: Category dropdown saves metadata; weights defined per section; calculation fallback uses points; filters and search apply dynamically; arrow keys and autofill supported; pacing guide integration applies zeros on missed due dates.

UI Elements: Header includes search bar, filter menu, autofill button; cell states indicate ungraded (red), resubmission (yellow), graded (neutral), exempt (gray 'E').

Error Handling: Validation for total weights = 100%; missing category defaults to Assignment; missing pacing guide shows warning; undo exempt triggers recalculation.

Data Handling: Assignments, grade weights, pacing data, and submissions stored in LMS database; integrates with assignment, pacing, and grading modules.

Acceptance Criteria: Teachers can configure and save valid weights, see correct color states for resubmissions, and use filtering/navigation efficiently.

Future Enhancements: Import/export weight templates, pacing analytics, color customization, dashboard features.
